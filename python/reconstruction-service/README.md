# Reconstruction Service (Python + FastAPI)

Not yet scaffolded. This service will expose HTTP endpoints for:
image-based pattern extraction, analytic expression evaluation
(sandboxed), 3D mesh reconstruction, and validation metrics.

Existing prototype code (`pattern_extractor/`) covers part of the
image-processing path and will be migrated into this service's
structure, not copied as-is — see open items tracked separately for
this module.

See the root [README.md](../../README.md) for architecture and the
root [CLAUDE.md](../../CLAUDE.md) for repository-wide conventions.
